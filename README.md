# Lý Chính Tân portfolio

Static English portfolio prepared for GitHub Pages. Open `index.html` locally to preview. No build tools, JavaScript, external fonts or package installation are required.

## Publish on GitHub Pages

1. In the `LCT-dotcom` GitHub account, create a repository named `LCT-dotcom.github.io`. If that repository already exists, integrate these files into the existing site rather than overwrite existing work.
2. Put `index.html`, `styles.css`, `favicon.svg` and `.nojekyll` at the repository root on the `main` branch.
3. Open **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, choose **main** and **/(root)**, then save.
5. Open the published URL shown in Pages settings. Initial publication may take up to ten minutes.

The intended user-site URL is `https://lct-dotcom.github.io/`. This is an intended destination, not a verified live deployment. Relative asset paths also support publishing this portfolio as a project site.

Official instructions: [GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart) and [publishing source configuration](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
